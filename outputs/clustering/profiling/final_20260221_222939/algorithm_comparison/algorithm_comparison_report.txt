Metric Interpretation
================================================================================

1. Silhouette Score (Range: -1 to 1)
   • Measures cluster cohesion and separation
   • Higher is better (>0.5 = strong, 0.2-0.5 = acceptable, <0.2 = weak)
   • Optimal: K-Means or GMM typically perform best

2. Davies-Bouldin Index (Range: 0 to ∞)
   • Measures cluster separation relative to cluster compactness
   • Lower is better (<1.0 = good separation)
   • Optimal: Hierarchical often achieves low scores

3. Calinski-Harabasz Score (Range: 0 to ∞)
   • Ratio of between-cluster to within-cluster variance
   • Higher is better (>1000 generally indicates well-defined clusters)
   • Optimal: K-Means often scores highest due to spherical cluster assumption

4. At-Risk Rate Stratification Range
   • Difference between highest and lowest cluster At-Risk rates
   • Higher indicates better risk differentiation for clinical utility
   • Optimal: Should maximize range for effective population stratification

================================================================================
Algorithm Characteristics
================================================================================

K-Means (BASELINE):
  ✓ Assumes spherical, equally-sized clusters
  ✓ Fast and scalable
  ✓ Requires pre-specified K
  ✓ Sensitive to initialization (mitigated by n_init=50)

Hierarchical Clustering:
  ✓ No assumption on cluster shape
  ✓ Deterministic (no random initialization)
  ✓ Can explore different K via dendrogram
  ✗ Computationally expensive for large datasets

DBSCAN:
  ✓ Discovers arbitrary-shaped clusters
  ✓ Automatically determines number of clusters
  ✓ Identifies outliers (noise points)
  ✗ Sensitive to eps and min_samples parameters
  ✗ Struggles with varying density clusters

Gaussian Mixture Model (GMM):
  ✓ Assumes Gaussian distribution of clusters
  ✓ Soft clustering (probabilistic assignment)
  ✓ More flexible than K-Means (elliptical clusters)
  ✗ Requires pre-specified K
  ✗ Can converge to local optima
